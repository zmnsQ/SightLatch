3 · 在手机上允许接管
App 填入板子 IP 和同一令牌，通过 App 打开 30 秒配对窗口。在 iPhone 辅助触控的蓝牙设备里配对 SightLatch；随后在 App 明确允许接管。每次最多 5 分钟，停止、断线或重启后保持关闭，不自动恢复。独立紧急停止可直接拔掉板子 USB 电源。
HTTP 是明文，仅使用自己控制的隔离受信局域网，不用于密码、支付等敏感操作。BLE Just Works 配对不防中间人，请在附近核对目标设备。


连接失败 / 没有串口？
使用可传数据的 USB 线，关闭 Arduino 串口监视器及其他占用端口的软件。按住板载 BOOT，短按 RESET，再松开 BOOT，然后重新连接。C3 BOOT 通常是 GPIO9，不能沿用经典 ESP32 的 GPIO0 说明；无需外接任何引脚。具体按键与驱动看板厂文档。安全启动或 Flash 加密设备不在支持范围，不要强制刷入。
烧录中断：不要把当前程序当作成功；按上述下载模式重新连接并完整重刷。成功写入不等于 BLE / iOS 行为验证通过。
