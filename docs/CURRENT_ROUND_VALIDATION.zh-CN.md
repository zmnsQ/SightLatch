# 本轮修改验证（2026-10-18）

本轮包含聊天首页、分组设置、设备检查与配对弹窗、计划后授权、辅助校准，以及固件 0.2.1 诊断和重复认证断连修正。

已在 Linux 云端验证：
- 所有 tests/check_*.py 源码契约检查通过。
- 全部 Swift 文件语法解析通过。此项不是 Apple SDK 类型检查或 Xcode 编译。
- 设备检查、配对、任务计划、硬件授权、代理循环、诊断导出测试通过；网络和硬件使用模拟输入。
- 辅助校准测试通过：七次用户标记、六次有限移动、实测拟合与独立验证、确认 STOP 后保存、取消与几何变化失效。
- 五种固件完整镜像的 4 MiB 大小、芯片类型与哈希通过验证。

待真实验证：Xcode 编译、iPhone UI、系统配对与录屏、真实 ESP32 蓝牙稳定性。不能将模拟测试称为实机通过。

校准目前需要用户在安全画布中点出实际指针位置，应用自动计算和验证；不是完全自动视觉校准。

固件已修正同一加密连接重复认证时被旧配对窗口误拒绝的路径，但未取得用户断连现场日志，不能保证该修正覆盖所有断连原因。

重要：当前网页提供的完整固件镜像会重写 NVS。升级前须准备重新配置 Wi-Fi、控制令牌和蓝牙配对。
